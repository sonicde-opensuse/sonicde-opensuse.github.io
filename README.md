## OpenSUSE TumbleWeed SonicDE-workspace rpms
You will find SonicDE-workspace,SonicDE-kwin-x11 and Sonic-Desktop-Interface in the x86 repo and the sources in SRPMS. The main workspace rpm contains languages for 90+% of computer users worldwide while the lang package contains the rest and is an optional add-on package. Workspace, Kwin and Desktop should also pull in their respective *.lib packages. Please add them if they do not.

## This is the initial version of SonicDE-workspace-Plasma-6.5.   
When KDE-Plasma-6.6 is updated on TumbleWeed I will package the   latest version of SonicDE. As always testing in a VM initially is prudent but that being said they "work for me" on my everyday desktop. They have also been tested on an ancient Toshiba Satellite laptop.   

1. Install SonicDE-Workspace/Kwin-x11/Desktop-Interface. Zypper/KDE will probably complain that you are overwriting files. Just say yes. 

2. The Sonic-Workspace/Kwin/Desktop lang and devel files are optional.

3. Have fun testing!!
